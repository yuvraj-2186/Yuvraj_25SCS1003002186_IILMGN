# Object-Oriented Programming with C++

This repository contains my academic work and practical implementations for the **Object-Oriented Programming using C++** course at IILM.

---

## 📚 Course Overview

The course focuses on building a strong foundation in **object-oriented programming concepts** and their implementation using C++.

### Key Concepts Covered
- Features and advantages of OOP over procedural programming
- Encapsulation, Abstraction, Polymorphism
- User-defined types: Structures and Unions
- Classes and Objects
- Access specifiers: private, public, protected
- Constructors and Destructors
- Function and Operator Overloading
- Inheritance (single, multiple, multilevel, hierarchical, hybrid)
- Virtual functions and Runtime Polymorphism
- Pointers to objects and dynamic memory allocation (`new` and `delete`)
- File handling in C++
- Templates and introduction to STL

## 💻 Practical Programs
